# adrianfernandezalv/tap

Homebrew tap for **[portent](https://getportent.pages.dev)**, a macOS menu bar app for developers running AI coding agents: dev servers and who started them, live Claude sessions, and Claude plan usage per account.

```bash
brew install adrianfernandezalv/tap/portent
```
